# V1 Home content map

Source inventory for [Home1 #2912](https://github.com/ORNL-AMO/VERIFI/issues/2912). Stable identifiers below connect legacy capabilities to the [Home dashboard specification](v1-home-dashboard-spec.md), which owns the accepted intended behavior. The [phase plan](v1-home-dashboard-plan.md) tracks remaining delivery. This map records dispositions, not implemented parity or issue closure.

Account means portfolio scope; facility also covers the sole facility in valid single-facility presentation. A row naming both scopes has the same capability with account/facility ownership differences called out. Retain means preserve the capability; Combine means deliver it within another widget/workflow; Exclude means an intentional omission from Home, with its existing owner/access preserved.

Default chart dispositions use built-in shipped configurations, without saved visualization records on view; explicit saved-chart reuse remains optional. This storage/creation distinction does not reduce the retained values, source meaning, tables or adapters below. The [specification](v1-home-dashboard-spec.md#built-in-defaults-and-saved-customizations) owns customization behavior, and the [phase plan](v1-home-dashboard-plan.md#first-usable-home-milestone) prioritizes complete built-in views before remaining capture breadth.

## Calculation and compatibility requirements

- **Utility observations:** preserve canonical calendarization, explicit included sources, precision, conversion and Site/Source meaning. Do not reuse mutable legacy presentation arrays as a new renderer contract. Actual observation months, fiscal years and named periods remain visible.
- **Comparison summaries:** D2's end month, same month a year earlier, monthly average and signed differences remain separate values. Preserve existing denominator/rounding semantics in an adapter; do not substitute a full-period year-over-year comparison or average the displayed rounded rows.
- **Costs:** include recorded costs from eligible energy, water and Other utility meters. Unknown/missing costs are distinct from a true zero. No budget goal, tariff estimate or monetized modeled savings is introduced.
- **Emissions:** preserve Scope 1 stationary/mobile/fugitive/process, Scope 2 electricity and other categories, and market versus location totals as supported by existing calculations. Do not sum market and location alternatives or imply a category breakdown adapter already exists.
- **Water:** retain intake versus discharge, their saved waterIntakeType/waterDischargeType subtypes, and owner display units; a combined table is not a new net-consumption formula. Do not silently add incompatible consumption meanings into a chart total or collapse different subtypes into source-only rows.
- **Analysis:** use full authoritative calculations, baselines, adjustments, banking, fiscal labels and current result horizons. V0 falls back to latest-modified analysis when no owner selection exists; the accepted Home rule intentionally replaces that fallback with explicit Active for reporting or a setup placeholder. Exact user-selected analysis charts remain pinned.
- **Goals:** read existing sustainability targets; no new goal types or linear expected-progress formula. Preserve goal year/baseline context and show missing/invalid results explicitly rather than copying legacy truthiness checks, zero fallbacks or negative-progress clipping.
- **Equipment:** no equipment-estimate area exists in these v0 Home/Overview pages. The separate Energy Use equipment section is an accepted addition, using the existing annual projection rather than claiming legacy measured-versus-estimated parity.
